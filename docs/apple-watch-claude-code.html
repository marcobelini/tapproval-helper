Approve Claude Code prompts from your Apple Watch

Claude Code stops and asks before it runs a command, edits a file or answers a question for you. If you are away from the keyboard, the session waits. This guide puts those prompts on your Apple Watch, so one tap on the wrist answers them and the session carries on.

It takes about five minutes. You need an Apple Watch on watchOS 10 or later, and Claude Code on a Mac or a Linux computer. Everything below is free, and there is no account to create.

1. Install the watch app

Get Tapproval on the App Store. It is not yet available in the EU; the TestFlight beta works everywhere.

2. Add the helper to Claude Code

The watch needs a small bridge on the computer, called Tapproval Base. It is open source and uses only Python's standard library. Type these two lines into Claude Code itself:

/plugin marketplace add marcobelini/tapproval-helper
/plugin install tapproval-helper@tapproval

Or just ask Claude Code in plain words:

Install the Tapproval plugin from marcobelini/tapproval-helper

The plugin registers a PermissionRequest hook, which is how Claude Code hands a prompt to the watch, and starts the relay with every session. How that hook works is explained on its own page.

3. Restart Claude Code

Quit Claude Code and run claude again. The helper starts when a session begins, so the session you installed it from cannot start it.

4. Open Tapproval on the watch

Open the app once while the watch and the computer are on the same Wi-Fi. It finds the computer by itself and pairs automatically. From then on it also knows how to reach the computer when you are away: through a private travel address.

What arrives on the wrist

  • Permission prompts, each marked with one of five risk tiers worked out on your computer. A force-push to main arrives as CRITICAL. Tap Allow or Deny.
  • Questions Claude asks you, with the same options as on the desktop.
  • Plans waiting for approval, with Approve, Approve & auto mode, Keep planning, or edits you dictate.
  • Your sessions: which one needs you, which is working, what it said. Reply, or start a new session from the wrist.

Nothing is approved for you. By default every prompt waits for a person. If you do not answer on the watch, the ordinary prompt is still there in Claude Code, exactly as it would be without Tapproval.

If the watch cannot find the computer

Almost every case is one of two things: the watch and the computer are on different networks, or a VPN on the iPhone is half connected. Open Settings → Connection on the watch; every route gets a tick or a reason. For a second watch, tell Claude Code Open Tapproval pairing and open the app within ten minutes.

Two buzzes for one prompt

If you also use Claude's Remote Control, the Claude app on your iPhone sends its own "permission needed" notification, and the watch shows that one too. Since Claude Code 2.1.278 it does so even for a prompt that has already been answered (claude-code#96126). To keep only Tapproval's card, type /config in Claude Code and turn off Push when actions required. The cost: if the watch cannot be reached, the phone no longer tells you a prompt is waiting.

Removing it

Tell Claude Code Uninstall Tapproval Base. It restores your settings, keeps a backup, and leaves nothing running. Delete the app from the watch like any other.
